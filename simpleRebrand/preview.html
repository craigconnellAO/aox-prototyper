Token proof

Each chip is painted by a semantic role, not a literal. Re-point the role in ao-theme.css and every component using it moves with it.

brand / default
--ao-action-primary-base
positive / default
--ao-ui-success-accent
danger / default
--ao-ui-error-accent
warning / default
--ao-ui-warning-accent
neutral / default
--ao-ui-dark-base
AO ext / accent
--ao-action-secondary-base

Worth knowing: AO defines --action-primary-base and --ui-success-accent as the same green (#00893e), so the brand and positive chips above are identical by design. Components must separate “this is the action” from “this succeeded” by shape and context, never by colour alone.
